# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

HTML5 semántico, Tailwind CSS (modern utility-first styling con tipografía e interactividad pulida), JavaScript vanilla modular. Estructura estática limpia lista para GitHub Pages y carga directa a GitHub web.

## Users

Reclutadores tech, tech leads, clientes potenciales de freelance y la comunidad de desarrolladores en Perú y Latinoamérica que evalúan el talento emergente, proyectos de software y habilidades técnicas de un estudiante de programación de Lima, Perú.

## Product Purpose

Landing page personal / portafolio profesional de alto impacto para un estudiante de programación en Lima, Perú. Presenta su perfil Full-Stack, proyectos prácticos con demos/código mock, stack tecnológico, trayectoria académica y canales de contacto directo (LinkedIn, GitHub, correo, WhatsApp).

## Positioning

Un portafolio personal que se desmarca de las plantillas genéricas: muestra criterio de ingeniería de software, código limpio, identidad local moderna (Lima, Perú - UTC-5), proyectos orientados a solucionar problemas reales (e-commerce, dashboard analítico, APIRESTful) y métricas de desempeño web impecables.

## Operating Context

Navegadores web modernos (Chrome, Firefox, Safari, Edge) en dispositivos móviles (smartphones) y de escritorio. Se desplegará y alojará en GitHub Pages o mediante repositorio público en GitHub.

## Capabilities and Constraints

- Carga ultrarrápida y sin dependencias pesadas de build complejas (directamente visualizable en local abriendo `index.html` o con Live Server).
- Secciones: Hero con presentación y estado de disponibilidad ("Open to internships / junior roles"), About me contextualizado en Lima, Skills & Tech Stack categorizado, Proyectos destacados (con tags, métricas y enlaces simulados), Trayectoria / Educación, y Contacto con formulario interactivo simulado y enlaces directos.
- Responsive design 100% móvil y desktop.
- Modo oscuro/claro o paleta nocturna de alta sofisticación técnica.
- Archivos y documentación listos para subir a GitHub (`README.md`, `.gitignore`, `index.html`, assets, etc.).

## Brand Commitments

- Tono profesional, enfocado, entusiasta y técnico.
- Identidad: "Santiago Rivera" (o customizable como estudiante de Ciencias de la Computación / Ingeniería de Sistemas en Lima, Perú).
- Sin clichés gráficos sobrecargados; diseño editorial técnico, limpio, tipografía nítida y microinteracciones fluidas.

## Evidence on Hand

- Estudiante de programación radicado en Lima, Perú.
- Proyectos mock representativos de desarrollo Full-Stack.
- Enfoque pragmático y código listo para inspección en GitHub.

## Product Principles

1. **Claridad sobre adorno**: Cada sección responde rápidamente a "¿quién es?", "¿qué construye?" y "¿cómo contactarlo?".
2. **Cero fricción**: El proyecto abre inmediatamente sin pasos de instalación (`npm install` no requerido si se usa distribución optimizada o CDN Tailwind moderna).
3. **Calidad de ingeniería visible**: Código HTML semántico accesible, estructurado y documentado para impresionar a un revisor técnico.
4. **Orgullo contextual**: Mención sutil y profesional de la zona horaria y ubicación (Lima, Perú / UTC-5) para oportunidades remotas o locales.

## Accessibility & Inclusion

Estándar WCAG AA para contrastes de color, navegación por teclado, soporte de lectores de pantalla con roles ARIA semánticos y rendimiento óptimo en conexiones de datos móviles.
